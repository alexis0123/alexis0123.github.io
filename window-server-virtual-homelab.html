Windows Server Virtual Homelab for Helpdesk

Platform & Tech: Virtualization & Infrastructure [Oracle VM VirtualBox, Windows Server, Windows 10, Active Directory Users and Computers (ADUC)]

The Windows Server Virtual Homelab replaces theoretical training with a multi-VM corporate infrastructure simulation. It establishes a centralized directory environment, allowing Tier 1 technicians to practice enterprise user management, policy compliance, and shared workstation resource mapping.

Key Features

Active Directory Infrastructure

Deployed a corporate domain forest (company.com) with segmented Organizational Units (OUs) to separate IT and Sales departments.

Enterprise User Management

Utilized ADUC to execute core helpdesk tickets including user account provisioning, security group delegation, and structural OU updates.

Compliance-Driven Security Protocols

Remediated account lockouts and enforced corporate password security policies by mandating "User must change password at next logon" resets.

Shared Folder Mapping

Configured a Windows File Server with centralized Shared Folders, deploying automated Map Network Drive configurations for end-user workstations.

Impact

Gained practical, hands-on experience navigating Active Directory environments to resolve common Tier 1 support tickets.

Learned how to properly enforce corporate security compliance during standard password resets and account creations.

Developed a strong foundational understanding of enterprise user account structures, group scopes, and network resource sharing.

Static Network Configuration

Configured manual IPv4 static addressing and subnetting options across all virtual machines within Oracle VirtualBox. This configuration establishes a reliable local sandbox routing environment, ensuring consistent host-to-guest networking connectivity and enabling seamless cross-machine communication without relying on dynamic DHCP leases.

Active Directory Forest & OUs

Established a secure root domain forest structure (company.com) using Active Directory Domain Services (AD DS). Organized the directory layout by partitioning separate Organizational Units (OUs) to mimic a corporate environment, successfully segmenting users, resources, and computers between the IT/Helpdesk and Sales departments.

Account Management & Security Policies

Utilized Active Directory Users and Computers (ADUC) to perform standard technical support ticket fulfillment workflows. Practiced advanced troubleshooting protocols for account lockouts, cleared blocked states, modified group objects, and enforced credential compliance by mandating the "User must change password at next logon" setting.

Shared Folder & Network Drive Mapping

Configured a centralized Windows File Server role containing accessible shared directory trees. Successfully provisioned network resource visibility and deployed a Map Network Drive configuration onto end-user client workstations, enabling automated file sharing across different business departments under strict resource access bounds.
